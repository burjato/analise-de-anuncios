# 📊 Análise de Eficiência em Anúncios de Vagas – Dashboard em Power BI

## 🏢 Visão Geral do Projeto

A **Out-of-the-Box Analytics Inc.** foi contratada para consultar a **Metro Staffing Inc.** sobre como otimizar a **alocação de gastos com anúncios de vagas**.  
Utilizando **insights orientados por dados**, o objetivo é avaliar a eficácia dos anúncios online da Metro Staffing no último mês e propor maneiras mais eficientes de distribuir o orçamento publicitário para melhorar os resultados de contratação.

A Metro Staffing forneceu um mês completo de dados sobre o desempenho dos seus anúncios de emprego, e esse conjunto de dados serve como base para a análise.

Este repositório contém o **relatório Power BI** desenvolvido para a avaliação preliminar dos principais indicadores de desempenho (KPIs) de publicidade e os dados de desempenho dos anúncios.

---

## 🎯 Objetivos

Como analista da **Out-of-the-Box Analytics**, suas responsabilidades foram:

1. **Importar o conjunto de dados para o Power BI**  
2. **Analisar três KPIs essenciais** que medem a eficácia dos anúncios de vagas  
3. **Apresentar descobertas e insights visualmente**  
4. **Recomendar próximos passos** para aprofundar a análise e otimizar a estratégia de anúncios  


---

## 📈 Indicadores de Desempenho (KPIs)

Os três KPIs selecionados representam métricas amplamente utilizadas no setor para avaliar o desempenho e a eficiência de campanhas de anúncios como: 

- **Custo por Clique (CPC)**  
- **Custo por Candidatura (CPA)**   

Cada KPI foi explorado no Power BI utilizando visuais interativos para identificar padrões de desempenho, comparar fontes de tráfego e determinar onde a Metro Staffing pode estar gastando em excesso ou investindo pouco.

---

## 🧠 Resumo da Análise

O relatório em Power BI inclui:

- Tendências e distribuição dos principais custos de anúncios  
- Comparações de desempenho entre diferentes plataformas/fontes  
- Identificação dos canais de anúncio com **maior retorno sobre investimento (ROI)**  
- Pontos de alerta para **ineficiências ou gastos excessivos**  
- Recomendações sobre os próximos passos para aprofundar a análise  

Essa exploração inicial fornece a direção estratégica necessária antes de avançar para modelagens mais avançadas.
